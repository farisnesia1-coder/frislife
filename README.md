# LIFE OS
Aplikasi produktivitas pribadi offline-first.

## Fitur
- Dashboard ringkas
- Daftar tugas dengan tenggat dan status selesai
- Pencatatan pemasukan/pengeluaran dan saldo otomatis
- Target tabungan dan setoran
- Catatan pribadi
- Focus timer 15/25/45 menit
- Ekspor dan impor backup JSON

## Data
Data disimpan di localStorage perangkat, tanpa database eksternal. Hapus data browser/aplikasi atau uninstall dapat menghilangkan data. Ekspor backup secara berkala. Timer hanya berjalan selama aplikasi terbuka.

## APK
Setiap push ke main menjalankan GitHub Actions untuk membungkus aplikasi menjadi APK Android debug. Buka tab Actions dan unduh artifact LIFE-OS-APK setelah workflow selesai.
